# PUENTE Creative OS Beta 0.1

Aplicación de prueba desarrollada con Streamlit. Ejecutar localmente con `pip install -r requirements.txt` y `streamlit run app.py`.

Para publicar: https://share.streamlit.io/ → Create app → Repository `puenteagenciavaldivia-code/puente-creative-os-beta` → Branch `main` → Main file `app.py`.

**Privacidad:** en esta beta no se almacenan respuestas en un servidor; cada participante descarga un JSON para enviarlo voluntariamente. No solicitar ni ingresar datos sensibles.

**Alcance técnico:** diagnóstico determinista experimental, no conectado a una API de IA ni a una base de datos. El resultado no aprueba automáticamente la estrategia creativa. Validar experiencia en Streamlit antes de compartir públicamente.
